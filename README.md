# 📊 Data Warehouse & Analytics Project

A modern data warehouse project built with PostgreSQL, following industry-standard data engineering practices.

This project demonstrates the complete process of transforming raw data from multiple source systems into analytics-ready datasets using a layered data warehouse architecture.

---

## 🚀 Project Overview

This project includes:

- Importing data from CRM and ERP systems
- Building a Bronze, Silver and Gold architecture
- Cleaning and transforming raw data
- Designing a Star Schema with fact and dimension tables
- Writing SQL queries to generate business insights

## 📂 Data Warehouse Architecture

```text
CRM + ERP
     │
     ▼
🥉 Bronze (Raw Data)
     │
     ▼
🥈 Silver (Cleaned Data)
     │
     ▼
🥇 Gold (Business Model)
     │
     ▼
Analytics & Reporting
```
